01 / The Project

A new take
on MWIII Warzone.

JUP9IW is an independent fan project centered on a custom client and mod for MWIII Warzone. This page tracks its goals, development and confirmed updates.

JUP9IW is an independent project developing a mod and custom client for the MWIII Warzone experience. Both are still in development.


The project aims to give its mod a dedicated client and a clear home for development updates. Technical details and the confirmed feature scope will be published as work progresses.


The project focuses on shaping the mod and its client as one coherent MWIII Warzone experience. Development notes will explain the goals, changes and direction as each part takes shape.
